# Chat Bot

This repository serves as a placeholder for a banking query chatbot developed as part of Gatim Technologies Private Limited. Due to company policies, the actual repository cannot be made public.

- # Features:
  - # Banking Query Handling:
      Developed a chatbot capable of answering banking-related queries efficiently.
  - # NLP with RASA
      Utilized RASA for natural language processing to understand user intents and extract relevant information.
  - # Time Extraction with Duckling
     Integrated Facebook's Duckling to accurately extract and process time-related details from queries.
  - # Python-Based Implementation
     Built using Python, ensuring scalability and ease of integration with various platforms.
